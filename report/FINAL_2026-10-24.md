  live prefight. `TeamIsKnockedOut` is not the blocker.

  libil2cpp base recipe and the InterfaceInjector state.

  changing team/hero/hp/pi/teamData cannot fill the prefight.

  `PreFightScreen.OnFight` (`0xE397BC`) NREs before any team code. The model is
  fetched only via `InterfaceInjector.Get<IPrefightDataProvider>`
  (`0x11E7640`) in `CacheReferences` (`0xE38F08`).
- Live injector: tag `tform`, 78 interface entries, one persistent
  (`IAdsProvider -> TFormIronSourceAdsModel`). Entry 0 has `tform`+`default`;
  the other 77 are `default`-only. The tag is already `tform` on HomeFlow.
- The earlier "team count 0" was a probe bug (List read with dictionary
  offsets); fixed. The current live team is count 1.
